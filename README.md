# SecureDrop: Smart Anti-Theft Food Delivery Locker
**UNM Robotics Society — EIRP 2026/2027**

## Team Members
- Lee Xinyi, Kee Xin Yi, Ho Zi Yi, Tan Hui Ying

## Project Overview
An automated, battery-powered, modular anti-theft smart food delivery locker for university campuses using an ESP32 DevKit V1, 5kg load cell (HX711), 12V solenoid lock, 2.8" SPI TFT touchscreen, FastAPI backend, and Telegram notifications.
